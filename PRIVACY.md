# Privacy Policy — Save Tabs

Save Tabs stores saved tab titles, URLs, tags, notes, sessions, sorting preferences, automatic-saving rules, and optional history snapshots in browser storage.

The extension does not sell, share, or transmit this data to third parties. Browser sync is disabled by default and only uses the browser's own sync service after the user enables it. Link checking is opt-in and sends a request only to links explicitly selected by the user.

Users can remove data at any time by deleting tabs, sessions, or the extension. Contact: manuel-garccia@hotmail.com.
