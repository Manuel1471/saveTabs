# Browser end-to-end checklist

Run this checklist in current Brave and Firefox before publishing a release.

1. Load the unpacked extension with at least three normal web tabs open.
2. Save current tabs, confirm cards and counter appear, then reopen the popup.
3. Select cards; open, pin, tag, note, delete, and undo deletion.
4. Switch ES/EN and verify controls, counts, empty states, and default session label.
5. Export a backup, import it, and confirm no duplicate URL is added within a session.
6. Open Settings from Rules; create, edit, disable, re-enable, and delete a domain rule.
7. Navigate to a matching domain and confirm the rule saves it to the target session.
8. Create a history snapshot, then restore it from History.
9. Enable sync, restart the browser, and confirm the opt-in state remains visible.
10. Confirm the privacy policy is accessible from Settings.
